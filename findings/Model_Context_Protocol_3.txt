Full specification page content (excerpt): MCP is an open protocol using JSON-RPC 2.0 for communication between Hosts (LLM apps), Clients (connectors), and Servers (provide context, tools, resources, prompts). Features include Resources, Prompts, Tools, and optional Sampling. Security principles: user consent, data privacy, tool safety, LLM sampling controls. Architecture similar to Language Server Protocol. Details on base protocol, stateful connections, capability negotiation, utilities (cancellation, logging).
